# Project Statement

## Problem Statement
A lot of games are hard to track and update. For example, if I wanted to add new words, I usually have to go into the code and change the variables myself. This makes the program hard to use for non-programmers. Also, most simple console games reset completely when you close them, so there is no way to track progress.

## Scope of the Project
My project is a text-based game that runs in the terminal. It focuses on separating the "logic" (the code) from the "data" (the words and scores).
* **In Scope:** Single-player mode, local file storage for scores, basic text interface.
* **Out of Scope:** Multiplayer, graphical user interface (GUI), or mobile app features. The project _is_ but a simple code-based game and I couldn't have included these.

## Target Users
* Anyone who likes retro-style puzzles.
* Students who want to improve their vocabulary.

## High-Level Features
1.  **Word Bank Management:** Reading data from external text files.
2.  **Score Tracking:** Reading and writing score data to the disk.
3.  **Game Logic:** Using loops and conditionals to track "lives" and "guesses."
