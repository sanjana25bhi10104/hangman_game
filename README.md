# hangman_Sanjana_Maity_[25BHI10104]

## Overview
This is a classic terminal-based Hangman game. It features a persistent high-score system.

## Features
- **Gameplay:** Classic word guessing logic.
- **Data Persistence:** Saves high scores to a file so they aren't lost.
- **File Handling:** Loads words randomly from a text file.
- **Input Validation:** Prevents crashing when invalid characters are entered.

## Technologies Used
- Language: Python 3.x
- Tools: Google Collab, Git

## How to Run
1. Download the code.
2. Open a terminal in the project folder.
3. Run the command: `python main.py`

## Testing
- Try entering numbers to see the error message.
- Win a game to see your score saved in `scores.json`.
